
# NextBest

A mobile app that helps you discover restaurants, activities, and entertainment. Spin a wheel to get personalized recommendations near you. Share with friends and vote together.

## Features

- **Randomizer** - Spin to get a random recommendation
- **Location-Based** - See places near you
- **Save Favorites** - Heart button to save picks
- **Share & Vote** - Send recommendations to friends, see voting results
- **Search** - Traditional browse if you prefer
- **User Profiles** - Manage friends and settings

## Tech Stack

- **Frontend:** Flutter (Dart)
- **Backend:** (Planned - Node.js/Python)
- **Database:** (Planned - Firebase/PostgreSQL)
- **APIs:** Google Places, Yelp

### Prerequisites
- Flutter 3.0+
- Dart 3.0+
